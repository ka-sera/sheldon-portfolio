# Profile Photo Setup Instructions

Your contact information has been updated! Now let's add your profile photo.

## Quick Steps

1. **Find your profile photo** (JPG or PNG format)
2. **Ideal specifications**:
   - Square aspect ratio (500x500px recommended)
   - Clear, professional headshot
   - File size under 200KB for best performance
   - PNG or JPG format

3. **Copy your photo** to the `images/` folder with the name `profile.jpg` or `profile.png`

4. **Update index.html**:
   - Open `index.html` in a text editor
   - Find this line (around line 50):
     ```html
     <img id="profileImg" src="images/placeholder-profile.jpg" alt="Sheldon Kasera" class="profile-photo">
     ```
   - Replace `placeholder-profile.jpg` with your photo filename:
     ```html
     <img id="profileImg" src="images/profile.jpg" alt="Sheldon Kasera" class="profile-photo">
     ```
   - Save the file

5. **Refresh your browser** to see the change

## ❓ Common Questions

**Q: How do I change colors?**
A: Edit `:root` variables in `css/styles.css`

**Q: Can I use a different design?**
A: The HTML/CSS structure is modular - you can customize colors, fonts, and layout

**Q: How do I add more sections?**
A: Edit `index.html` to add new sections and style them in `css/styles.css`

**Q: Is my data secure?**
A: GitHub Pages is static hosting - no backend database. Contact form data goes through EmailJS securely.

**Q: Can I use my custom domain?**
A: Yes! GitHub Pages supports custom domains (see GitHub settings)
